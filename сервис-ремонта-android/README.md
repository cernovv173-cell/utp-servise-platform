# UTP Servise — Android

Нативное Android-приложение на Kotlin и Jetpack Compose. Имя «UTP Servise» и изображение в `app/src/main/res/drawable-nodpi/utp_servise_logo.jpg` используются на главном экране.

## Сборка

Откройте проект в Android Studio с JDK 17, Android SDK 36 и Gradle 8.11.1 либо используйте Gradle Wrapper, если он настроен. Эмулятор и физическое устройство в среде Amazi недоступны.

## Ограничения текущей версии

Интерфейс экранов, локальное заполнение заявки и переходы между вкладками реализованы. Авторизация, отправка заявок в сервис, чат, роли мастера/администратора, push-уведомления и карточная оплата требуют серверной реализации и внешних подключений; кнопка заявки пока не отправляет данные на сервер. ЮKassa недоступна для подключения по текущему тарифу проекта.
