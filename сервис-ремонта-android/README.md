# UTP Servise — Android

В карточке заказа показываются услуги и запчасти из общего каталога с количеством, ценой и суммой. Администратор может пополнять прайс, редактировать и отключать позиции; мастер выбирает активные позиции только для назначенных ему заказов. Сервер фиксирует цену при добавлении, а уже оформленные строки сохраняются при изменении прайса.

На клиентской главной отображаются опубликованные новости. Администратор может создавать черновики, редактировать новости, публиковать и снимать их с публикации. Клиенты и мастера не получают черновики.

В карточке заказа клиент и назначенный мастер могут открыть сохранённый чат. Мастер может передать вопрос администратору; запрос появится в разделе управления, администратор подключится к беседе и сможет ответить. Открытая беседа обновляется автоматически; отдельные push-уведомления не настроены.

Удаление строк заказа, онлайн-оплата, push-уведомления и публикация APK в Google Play в текущую версию не входят.

Нативное приложение на Kotlin и Jetpack Compose для ремонта компьютеров, ноутбуков, телефонов и планшетов. Логотип и название UTP Servise размещены в приложении.

## Реализованные сценарии

- Отдельные порталы входа клиента, мастера и администратора. Публичная регистрация создаёт только клиента; выбрать себе роль сотрудника нельзя.
- Клиент создаёт заявку, видит только собственные заказы и историю, может отменить только новую заявку и оставить один отзыв после завершения ремонта.
- Мастер видит только назначенные ему заказы, начинает и завершает ремонт по разрешённой последовательности статусов.
- Администратор просматривает все заказы, назначает активного мастера, управляет рабочими учётными записями и видит отзывы.
- Пароли хранятся как scrypt-хеши, токены сессий — только в виде хеша на сервере; токен на Android хранится зашифрованным Android Keystore.
- Все существенные действия проверяются сервером, а не только скрытием экранов. История статусов хранится в базе.

## Сборка

```bash
./gradlew :app:assembleDebug --no-daemon --max-workers=2
```

Требуются JDK 17, Android SDK 36 и переменная сборки `UTP_API_BASE_URL` с HTTPS-адресом сервера. APK, собранный в среде проекта, настроен на адрес разработки. Производственный API ещё не опубликован, поэтому этот APK не следует считать производственным выпуском. Эмулятор и физическое устройство в среде Amazi недоступны.

## Границы текущей версии

API и база работают в среде разработки; миграция ролей, заказов, истории и отзывов применена. Начальная административная учётная запись создана, одноразовые bootstrap-переменные удалены. Платёжная интеграция, чат и push-уведомления не включены: они требуют отдельных подключений и реализации. Публикация API или приложения в Google Play не выполнялась.
