# Материалы RuStore — ЕНОТ СЕРВИС для Android

## Актуальный комплект

- Версия: `1.5.62` (`versionCode` 96), пакет `ru.utp.servise`.
- Минимальная версия Android: 8.0 (API 26).
- Папка текстов карточки и заметок: `release-1.5.62/`.
- Подписанный APK версии 1.5.62 приложен к сообщению отдельно; в RuStore он не загружался.
- Источник нового енота: `source-art/utp-raccoon-mascot-1024.png`.
- Новый енот используется в логотипе внутри приложения, значке установленного приложения и значке карточки магазина.

## Важно перед отправкой

RuStore требует значок 512 × 512 px с непрозрачным фоном и не менее трёх актуальных снимков реального интерфейса для телефона. Изображения в `release-1.5.42/promo/` — рекламные иллюстрации, а не скриншоты приложения; не загружайте их вместо скриншотов. Старые файлы в `screenshots/` сняты для версии 1.5.27 и содержат устаревшие экраны, поэтому их также нельзя выдавать за актуальные.

В среде сборки нет подключённого Android-устройства или эмулятора, поэтому свежие снимки версии 1.5.62 не сделаны. Перед модерацией снимите на телефоне не менее трёх актуальных экранов.

## Перед отправкой версии

1. Загрузите подписанный APK `UTP-Servise-1.5.62-96.apk`, приложенный к сообщению.
2. Убедитесь, что значок RuStore совпадает с новым значком установленного приложения.
3. Добавьте свежие скриншоты реального интерфейса; рекламные иллюстрации оставьте для промоматериалов.
4. Внесите краткое и полное описания из папки `release-1.5.62/`.
5. Проверьте политику конфиденциальности: `https://xn----dtbhbq0ahshee.xn--p1ai/privacy-policy.html`.
6. Сверьте декларацию данных и разрешений с `console-checklist.md`, заполните категорию, рейтинг и контакты разработчика.
7. Вставьте текст `release-1.5.62/whats-new.txt` и отправьте версию на модерацию.

Текущий комплект подготовлен для ручной загрузки владельцем в RuStore; приложение в консоль магазина автоматически не отправлялось.
