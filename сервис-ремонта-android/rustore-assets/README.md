- Пакет: `ru.utp.servise`
- Версия: `1.5.27` (`versionCode` 61)
- Минимальная версия Android: 8.0 (API 26)
- Иконка: `icon-512.jpg`, 512 × 512 px
- Скриншоты телефона: пять вертикальных JPEG-файлов из архива `utp-servise-rustore-screenshots.zip`

В папке также лежит `06-launch-art-not-for-listing.jpg`. Это иллюстрация, а не снимок экрана; не загружайте её как скриншот приложения.

## Перед отправкой версии

1. Загрузите подписанный `app-release.apk` из ответа агента.
2. Проверьте, что в карточке указана политика: `https://xn----dtbhbq0ahshee.xn--p1ai/privacy-policy.html`.
3. Загрузите иконку и не менее трёх актуальных скриншотов телефона; для этого набора выбирайте вертикальную ориентацию.
4. Заполните категории данных и объяснение разрешений по `console-checklist.md`.
5. Добавьте текст обновления из `whats-new.txt`, выберите категорию и возрастной рейтинг в консоли, затем отправьте версию на модерацию.

Скриншоты предоставлены владельцем проекта и проверены по формату, размеру файла и разрешению. Они не были повторно сняты с APK 1.5.27 на эмуляторе или физическом устройстве.
