# Комплект RuStore — ЕНОТ СЕРВИС 1.5.62

Тексты карточки для текущей версии приложения. Подписанный APK `UTP-Servise-1.5.62-96.apk` приложен к сообщению отдельно; в RuStore он не загружался.

- `short-description.txt` — краткое описание карточки.
- `full-description.txt` — полное описание с актуальным перечнем услуг.
- `whats-new.txt` — текст для поля «Что нового?».

Перед отправкой добавьте свежие снимки актуального интерфейса: старые скриншоты в `../screenshots/` относятся к версии 1.5.27, а изображения из `../release-1.5.42/promo/` являются рекламными материалами, не снимками приложения.
