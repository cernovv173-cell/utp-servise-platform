# Скриншоты для RuStore — версия 1.5.42

Перед отправкой на модерацию снимите не менее трёх вертикальных экранов непосредственно из актуальной версии приложения на телефоне. Используйте только реальные экраны; не заменяйте их рекламными иллюстрациями из `promo/`.

Рекомендуемый набор:

1. Главный экран клиента с актуальными разделами.
2. Создание заявки или карточка текущего ремонта.
3. Список техники/напоминаний либо чат по заявке.

Старые снимки из `../screenshots/` относятся к версии 1.5.27, поэтому их нельзя загружать без повторной проверки на установленной версии 1.5.42. Требования RuStore: PNG/JPG, не более 3 МБ каждый, максимальный размер 2160 × 3840 px; для каждого типа устройства нужно не менее трёх изображений.
