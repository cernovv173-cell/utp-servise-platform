# Комплект RuStore — ЕНОТ СЕРВИС 1.5.42

В комплект входят готовые тексты карточки, новый логотип и три рекламные иллюстрации для страницы сервиса.

## Файлы

- `icon-512.png` — непрозрачный значок 512 × 512; тот же енот показан в приложении и в значке на телефоне.
- `promo/*.jpg` — три вертикальные рекламные иллюстрации 1080 × 1920. Это созданные для сервиса промоматериалы, а не снимки интерфейса.
- `source-art/` — исходные изображения енота и трёх мастерских сцен в полном разрешении.
- `short-description.txt` и `full-description.txt` — тексты карточки.
- `whats-new.txt` — текст для поля «Что нового?».
- `screenshots-needed.md` — список актуальных снимков интерфейса, которые ещё нужно сделать на телефоне.
- `release-manifest.md` — сведения о подписанной сборке, контрольной сумме и проверках.

## Скриншоты

RuStore просит загрузить не менее трёх скриншотов реального актуального интерфейса для каждого типа устройств. Старые картинки в `../screenshots/` сняты для версии 1.5.27, а рекламные иллюстрации из `promo/` скриншотами не являются. В среде сборки не подключены телефон и эмулятор, поэтому свежие снимки для 1.5.42 сюда не включены. Не отправляйте промоматериалы в поле скриншотов.

## Внутренняя заметка по уведомлениям

В APK есть фирменный звук «Мягкая искра» и отдельный канал поздравлений с победой. Чтобы серверные push о победе использовали отдельный канал в рабочей версии, требуется отдельно опубликовать соответствующее обновление API. В рамках подготовки APK API не публиковался.

Сам APK приложен отдельно: `enot-servis-1.5.42-release.apk`.
