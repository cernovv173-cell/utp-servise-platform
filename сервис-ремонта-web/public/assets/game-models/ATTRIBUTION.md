# Game 3D model assets

The workshop props below are locally bundled glTF 2.0 assets from Poly Haven. Both are CC0;
the game uses the 1K texture variants to keep download and GPU texture costs low.

| Asset         | Creator                                              | Source                                | License |         Geometry |
| ------------- | ---------------------------------------------------- | ------------------------------------- | ------- | ---------------: |
| Metal Toolbox | Mateusz Sadek                                        | https://polyhaven.com/a/metal_toolbox | CC0     | 14,228 triangles |
| Bench Vice 01 | Antanas Kep (model/textures), Yann Kervran (rigging) | https://polyhaven.com/a/bench_vice_01 | CC0     |  2,864 triangles |

Each model is served from the game's own assets directory; the game does not request these files
from the source sites at runtime.
