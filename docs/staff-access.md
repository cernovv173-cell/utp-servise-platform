# Сотрудники и помощники администратора

- Администратор может создать помощника из раздела управления сотрудниками; учётная запись
  помощника отображается отдельным типом, но использует тот же административный рабочий доступ.
- Помощник может выполнять административные операции и создавать клиентов, мастеров,
  сотрудников закупки и других помощников. Создать запись с полноценной ролью администратора
  может только администратор. Сервер повторно проверяет это ограничение — скрытия пункта в форме
  недостаточно.
- Помощник входит как администратор и использует те же интерфейсы Web/Android и MAX-привязку.
  Флаг помощника не меняет полномочия аккаунта в MAX и не позволяет получить роль через публичную
  регистрацию.
- При постоянном увольнении сотрудник исчезает из рабочего списка. Его аккаунт, история заказов,
  чеки и начисления сохраняются; сессии закрываются, а незавершённые заявки возвращаются в очередь
  для переназначения.
- В системе должен оставаться как минимум один активный полноценный администратор. Помощники не
  считаются полноценными администраторами для этого защитного правила.
